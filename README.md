# Verified-RAG
Verified Multi-Agent RAG for Hallucination-Resistant Technical Question Answering.

## Structure
- `notebooks/`: Step-by-step development and experiment notebooks.
- `src/`: Core modular pipeline (retrieval, agents, verification, evaluation).
- `data/`: Extracted corpus, processed chunks, and FAISS index.
- `experiments/`: Experiment configurations and trial logs.
- `results/`: Benchmark metrics and ablation outputs.
- `app/`: Interactive demo and verification interface.
